📘 Setup Guide

Device IP: loading...

1 Connect to WiFi

On first boot the device creates an AP named ESP32-Doorbell. Connect to it and open http://192.168.4.1 to enter your home WiFi credentials.

2 Enable Camera & Streaming

Go to ⚙️ Feature Setup and enable HTTP Camera Streaming and/or RTSP Camera Streaming. Save and reboot if prompted.

Then verify the camera is live by clicking 📸 Snapshot or 🎥 Live Stream on the main page.

3 Configure SIP (Fritz!Box)

Go to ⚙️ SIP Setup and fill in your Fritz!Box credentials. See the tab for detailed registration steps.

4 Add to Scrypted / HomeKit

See the tab for the RTSP URL and required FFmpeg settings.

RTSP Stream URL

rtsp://DEVICE_IP:8554/mjpeg/1

Use this URL in the Scrypted FFmpeg Camera plugin (recommended) or RTSP Camera plugin.

FFmpeg Camera Plugin — Recommended Setup

  1. In Scrypted, add a new device → FFmpeg Camera.
  2. Set the stream URL to the RTSP URL above.
  3. Under Output Prefix, paste the following (required for HomeKit Secure Video compatibility):
-c:v libx264 -pix_fmt yuvj420p -preset ultrafast -bf 0 -g 60 -r 15 -b:v 500000 -bufsize 1000000 -maxrate 500000

Without this prefix, Scrypted defaults to mpeg4 which is incompatible with HomeKit's WebRTC pipeline.

  1. Assign the Doorbell role to the device in Scrypted.
  2. Pair with HomeKit — the doorbell will appear with live view, two-way audio, and rich notifications.

HomeKit Doorbell Ring Webhook

Copy the Scrypted webhook URL for this device, then paste it into ⚙️ Feature Setup under Webhook URL. The ESP32 will POST to it on each button press, triggering a HomeKit ring event.

MJPEG Stream (alternative / HTTP Camera plugin)

http://DEVICE_IP:81/stream

Lower latency than RTSP for single-viewer use. Not recommended for HomeKit (no audio, no H.264).

Snapshot URL (Fritz!fon / NVR thumbnail)

http://DEVICE_IP/capture

Returns a single JPEG. Useful for Fritz!fon live image, NVR event snapshots, or monitoring scripts.

Register as IP Door Intercom (Türsprechanlage)

Important: The device must be registered as a Türsprechanlage (IP Door Intercom), not a plain SIP telephone. This unlocks the "Talk" and "Open" buttons on Fritz!fon and enables the live image.

  1. Open Fritz!Box UI → Telefonie → Telefoniegeräte → Gerät hinzufügen.
  2. Select Türsprechanlage.
  3. Fill in a name (e.g. ESP32-Doorbell), username, and password. Note these — they go into ⚙️ SIP Setup.
  4. Under Klingeltaste 1, set the ring target to your phone group number (e.g. **11 for Erdgeschoss).
  5. Under Live-Bild, enter the snapshot URL:
http://DEVICE_IP/capture
  1. Save. The device will appear under Telefoniegeräte as an IP door intercom.

SIP Credentials

In ⚙️ SIP Setup, configure:

  • SIP Server: your Fritz!Box LAN IP (usually 192.168.178.1)
  • Username: the username set in Fritz!Box (e.g. doorbell)
  • Password: the password set in Fritz!Box
  • Ring Target: the phone group number (e.g. **11)

Door Opener (Fritz!fon "Open" button)

When a Fritz!fon user presses Open during a call, Fritz!Box sends DTMF tones 1 → 2 → 3 via SIP INFO. The ESP32 detects this sequence and pulses the door opener relay (GPIO1) for the configured duration.

Adjust the pulse duration in ⚙️ Feature Setup → Door Opener Pulse.

Ring Target Format

  • **11 — Ring the Erdgeschoss phone group
  • **610, **611 — Ring individual Fritz!fon handsets
  • **9 — Ring all phones

Check your Fritz!Box internal numbers under Telefonie → Eigene Rufnummern → Interne Rufnummern.

Gong Relay (original chime)

GPIO3 controls a relay that bridges the original 8 VAC doorbell chime circuit. When a call is triggered, the gong relay fires for the configured duration (default 800 ms) before the SIP call connects. Adjust in ⚙️ Feature Setup → Gong Relay Pulse.

OTA Firmware Update

  1. Enable OTA in ⚙️ Feature Setup.
  2. Navigate to /ota and upload a .bin firmware file.
  3. To update web assets only, upload the littlefs.bin partition image instead.

Log Viewer

View real-time logs at /logs.html. Filter by:

  • Core — WiFi, NVS, web server
  • Camera — MJPEG, RTSP, frame stats
  • Doorbell — button, relay, SIP events
  • RTSP — RTSP session and RTP detail

Reset NVS / Factory Reset

Clearing WiFi credentials via Forget WiFi on the main page reboots the device into AP mode. NVS settings (SIP config, relay durations, camera settings) are preserved. To fully erase NVS, re-flash with idf.py erase-flash before uploading firmware.
